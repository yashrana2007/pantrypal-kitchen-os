6.1 Purpose

The PantryPal Design Language (PDL) establishes the visual and interaction standards that define the PantryPal experience.

Every screen, animation, icon, component, and interaction should follow these principles to ensure a consistent, recognizable, and human-centered product.

The goal of PDL is not to make PantryPal look beautiful.

The goal is to make PantryPal feel effortless.

6.2 Design Philosophy

PantryPal follows one simple philosophy:

Calm technology for everyday kitchens.

Technology should quietly support users rather than demand attention.

Design should communicate clarity before creativity.

Every visual element should have a purpose.

6.3 Design Keywords

Every design decision should reflect these six qualities:

🌿 Natural

✨ Minimal

🏡 Warm

🧠 Intelligent

💚 Trustworthy

🎯 Purposeful

If a design doesn't reflect these words, it should be reconsidered.

6.6 Spacing System

PantryPal follows an 8-point spacing grid.

Standard spacing values:

4 px
8 px
16 px
24 px
32 px
48 px
64 px

Consistent spacing creates visual rhythm and improves readability.

6.7 Corner Radius

Buttons → 14 px

Cards → 20 px

Bottom Sheets → 28 px

Floating Action Button → Circular

App Icon → 28 px

Rounded corners reinforce PantryPal's friendly personality.

6.8 Shadows

Only one shadow style should be used throughout the app.

Soft

Subtle

Natural

Cards should appear to gently float rather than cast heavy shadows.

6.9 Icons

Icon Style:

Rounded Outline

2 px Stroke

Simple Geometry

Minimal Detail

Icons should communicate quickly without visual clutter.

6.10 Motion Principles

Animations should never exist simply for decoration.

Every animation should communicate state or improve understanding.

Animations should feel:

Smooth
Calm
Predictable
Purposeful
6.11 Motion Language

Small animations include:

Card Press
Bottom Sheet Slide
Progress Ring Fill
Kitchen Zone Tap
Fridge Door Opening
Drawer Sliding
Success Celebration

Motion should never delay interaction.

6.12 Living Kitchen

The kitchen environment should evolve naturally.

Changes include:

Morning

Afternoon

Evening

Night

Rain

Winter

Summer

Festivals

Inventory

Kitchen Health

These changes create emotional attachment without distracting users.

6.13 Accessibility

Every interface should remain comfortable for all age groups.

Guidelines:

Large touch targets
Clear typography
High color contrast
Minimal scrolling
Clear navigation
Simple language

Accessibility is considered part of good design—not a separate feature.

6.14 Bottom Navigation

Only four primary destinations exist.

🏠 Home

🏡 My Kitchen

🍽 Planner

📊 Insights

No hamburger menu.

No side drawer.

No unnecessary navigation layers.

6.16 Interaction Model

Users should never feel lost.

General interaction rules:

Tap → Open

Long Press → Quick Actions

Swipe → Secondary Actions

Bottom Sheet → More Details

Every interaction should feel predictable.

6.17 Design Non-Negotiables

The following rules must never be broken:

Home remains minimal.
My Kitchen remains immersive.
Every recommendation explains itself.
No unnecessary animations.
Every color has meaning.
Every icon has a purpose.
Every screen should answer one question.
6.18 Why This Chapter Matters

The PantryPal Design Language ensures that every future screen, feature, and interaction feels like part of the same product.

It allows PantryPal to grow while maintaining a consistent personality and user experience.

🌿 PantryPal Principle

Good design is not what users notice. It's what they don't have to think about.
