🌿 Kitchen Canvas Principles

Before registering components, define the rules.

Kitchen Canvas Principles
1. Spatial Reality

Every component must exist where users naturally expect it in a real kitchen.

2. Real Object First

Every component represents a real kitchen object before becoming a digital interaction.

3. Progressive Disclosure

Objects remain visually calm.

Information appears only after interaction.

4. One Focus at a Time

Only one Kitchen Insight Card is visible.

5. Living Environment

Objects evolve with:

Time
Inventory
User activity
Kitchen state
