Naming Convention.md
Component ID Format
PCR-[CATEGORY]-###

Examples

PCR-EXP-001

PCR-INT-004

PCR-UI-012

PCR-KC-005
Naming Rules

Names should:

Describe the component.
Avoid abbreviations.
Be singular.
Be reusable.
Be product-independent where possible.

Example

✅ Kitchen Ready Hero

❌ Home Hero
