3.1 Button Family

Project: Evergreen

Version: 1.0 Alpha

Status: 🟢 Approved (Pending Visual QA)

3.1.1 Overview

The Button Family provides a consistent set of interaction components across PantryPal.

Buttons guide users through actions while maintaining visual hierarchy and accessibility.

The PantryPal Button Family consists of nine standardized components designed to cover nearly every interaction within the application.

3.1.11 Loading Button
Purpose

Communicates that an action is currently in progress.

Behaviour

Instead of changing the button size:

Replace the label with a spinner.
Maintain the same width.
Disable additional taps.
Rules

Loading should never block the entire screen unless absolutely necessary.

3.1.12 Accessibility

Every button must satisfy the following accessibility requirements.

Requirement	Value
Minimum Touch Target	48 × 48 px
Preferred Touch Target	56 × 56 px
Contrast Ratio	Minimum 4.5 : 1
Keyboard Focus	Supported
Screen Reader Label	Required

3.1.15 Do
Keep labels concise.
Use one primary action.
Maintain consistent sizing.
Reuse existing button components.
3.1.16 Don't
Create custom button styles.
Use multiple Primary Buttons together.
Overuse red buttons.
Add decorative icons without meaning.
