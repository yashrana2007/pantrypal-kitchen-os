3.7 Iconography

Project: Evergreen

Version: 1.0 Alpha

Status: 🟡 In Review

3.7.1 Purpose

The PantryPal Iconography System provides a unified visual language for actions, navigation, status, and kitchen-related information.

Icons should improve recognition, reduce reading effort, and make the interface feel approachable.

They should support content—not replace it.

3.7.2 Icon Philosophy

Every icon should answer one question instantly.

"What does this represent?"

Icons should be immediately recognizable without requiring interpretation.

3.7.3 Design Principles

All PantryPal icons should be:

Simple
Friendly
Rounded
Consistent
Minimal
Timeless

Avoid excessive detail or decorative styling.

3.7.4 Icon Style

PantryPal uses:

Rounded outlines
2 px stroke
Consistent corner radius
Minimal internal details
Soft geometric construction

Icons should feel warm and modern rather than technical.

3.7.7 Color Usage

Icons should inherit semantic colors.

Default:

Charcoal

Success:

Green

Warning:

Amber

Error:

Red

Information:

Blue

Avoid decorative gradients.

3.7.8 Filled vs Outline

Default:

Outline

Selected Navigation:

Filled

Achievements:

Filled

Alerts:

Filled only when emphasis is required.

3.7.9 Accessibility

Icons should never communicate meaning through shape alone.

Every important icon should be paired with:

Text
Tooltip
Label
3.7.10 Motion

Icons may support subtle animations.

Examples:

Search → Gentle pulse while active
Success → Soft check reveal
AI → Gentle orbit animation
Kitchen Ready → Leaf growth

Animations should remain calm and purposeful.

3.7.11 Do
Use simple geometry.
Keep strokes consistent.
Reuse icons.
Maintain visual balance.
3.7.12 Don't
Mix multiple icon styles.
Use excessive detail.
Overuse filled icons.
Distort proportions.
3.7.13 Future Expansion

🌿 Evergreen Principle

Icons should feel familiar enough to recognize instantly, yet distinctive enough to feel uniquely PantryPal.
